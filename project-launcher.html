Launch kinds

Local folder
Opens a folder on this machine — vscode://file/<path>/.
SSH folder
Opens a plain remote folder over SSH, no container involved.
SSH devcontainer
SSHes in, then attaches to that folder's .devcontainer/devcontainer.json.
WSL
Opens a folder inside a WSL distro — vscode://vscode-remote/wsl+<distro>/<path>.

Every launch link carries ?windowId=_blank so it always opens a fresh VS Code window instead of hijacking whichever one currently has focus.

Color schemes

Manual
Whatever bg/fg is saved for that tile.
Hash → palette
Each project's name is hashed into one of ~14 curated colors — stable, zero setup.
Family clustering
Projects with related names (e.g. Foo, Foo_Public, Foo_Test) auto-share a hue, shaded by variant — an automatic approximation of hand-picking a color per project family.
By launch kind
Color tells you the mechanism: local, ssh, devcontainer, and wsl each get their own hue.
Alphabetical rainbow
Purely visual — a hue sweep across the sorted project list.

Switching schemes only changes what's rendered — it never writes to projects.json.

Taskbar tip: each project's own .vscode/settings.json can set window.title and workbench.colorCustomizations (titlebar bg/fg) — the same emoji + color you picked for its tile here. Do that consistently and your Windows taskbar and Alt-Tab switcher show a distinct emoji + title per window, so switching between several open VS Code windows is as fast as picking a tile here in the first place.
